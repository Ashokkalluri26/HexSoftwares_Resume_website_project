# Professional Resume Web Application

A clean, responsive, and professional resume web application built with HTML and CSS.

## Features

- Responsive design that works on all devices
- Clean and professional layout
- Easy to update and customize
- Print-friendly styling
- Organized sections for education, skills, and experience

## How to Use

1. Clone this repository
2. Open `index.html` in your web browser
3. To make changes, edit the `index.html` file

## Customization

To customize this resume with your own information:
1. Update the personal information in the header section
2. Modify the education and experience sections as needed
3. Update the skills list with your own skills
4. Add or remove sections as required

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
